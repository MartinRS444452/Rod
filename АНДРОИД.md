# «Род» как приложение на Android

Три способа — от самого простого. **Первый подходит почти всем.**

## 1. Установить как приложение (PWA) — 1 минута, ничего собирать не нужно ✅

«Род» уже умеет устанавливаться: Chrome проверил его на соответствие требованиям (ошибок установки нет; проверка входит в автотесты).

**У вас (сервер в Termux):**
1. Запустите сервер (`npm start`) и откройте в Chrome `http://127.0.0.1:3000`.
2. Меню «⋯» в самом «Роде» → «Установить приложение» (или меню Chrome ⋮ → «Установить приложение» / «Добавить на главный экран»).
3. На экране появится значок «Род». Он открывается без адресной строки, как обычное приложение.

**У родственников (сервер в интернете, см. `ДОСТУП-ИЗ-ИНТЕРНЕТА.md`):** открыть полученную ссылку-приглашение в Chrome → зарегистрироваться → ⋮ → «Установить приложение». Условие — адрес **с https** (для `http://IP` Chrome установку не разрешает; исключение — `localhost`/`127.0.0.1` на том же устройстве).

Что работает в установленном виде: вход, правки, синхронизация между устройствами, фото (в том числе выбор из «Google Фото»), скачивание архивов и полной копии, офлайн-просмотр последней версии древа, обновления без переустановки.

## 2. Настоящий APK из вашего HTTPS-адреса (PWABuilder) — если нужен файл `.apk`

Подходит, когда у сервера есть публичный адрес с HTTPS (способы 1–2 из `ДОСТУП-ИЗ-ИНТЕРНЕТА.md`; для временного адреса туннеля — не имеет смысла).
1. Откройте pwabuilder.com, вставьте адрес сервера, нажмите «Start». Манифест уже содержит всё нужное (иконки, maskable, скриншоты, `id`).
2. «Package for stores» → Android → Generate. Скачается архив с APK (и ключом подписи — **сохраните его**, без него приложение не обновить).
3. Чтобы приложение открывалось **без адресной строки**, нужен файл подтверждения. PWABuilder даст его содержимое (`assetlinks.json`). Положите файл в папку данных сервера: `~/rod/data/assetlinks.json` (в Docker — `./data/assetlinks.json`), сервер сам отдаст его по адресу `/.well-known/assetlinks.json`. Без этого шага приложение будет работать, но с полоской адреса сверху.
4. Установите APK на телефон (разрешите установку из неизвестных источников) или, если есть аккаунт разработчика Google Play (разовый платёж), опубликуйте приложение.

Такое APK внутри использует Chrome, поэтому скачивание файлов, выбор фото и офлайн работают как в способе 1.

## 3. Оболочка Capacitor (папка `android/`) — запасной вариант

Простое окно с вашим сервером (адрес вводится при первом запуске). Не собиралась и не проверялась; **кнопки скачивания файлов в ней не работают** (ограничение WebView). Подробности — `android/README.md`.

## Что проверено, а что нет

Проверено автотестами и в Chromium: манифест без ошибок, установка возможна, все иконки и скриншоты манифеста отдаются сервером с правильным типом, `assetlinks.json` отдаётся только когда файл положен в `data/`. **Не проверено**: сама установка на вашем телефоне, сборка APK через PWABuilder и Capacitor (нужны интернет и Android SDK) — если что-то пойдёт не так, напишите, на каком шаге и что показывает экран.
