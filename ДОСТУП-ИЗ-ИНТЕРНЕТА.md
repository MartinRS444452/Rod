# Как пустить родственников из их домов

Сейчас «Род» работает на вашем телефоне, поэтому он виден только в вашей Wi‑Fi. Чтобы родственники вносили данные из своих домов, нужно сделать сервер доступным из интернета **по HTTPS** и дать им **ссылки-приглашения**. Приглашения уже есть в приложении; доступ из интернета — три способа ниже.

## Что уже сделано в самом приложении

- **Регистрация только по приглашению** (по умолчанию). Посторонний, найдя адрес, аккаунт не создаст. Первый аккаунт (ваш) создаётся без приглашения.
- **Меню слева → «Пригласить по ссылке…»** (у владельца древа): указываете, для кого, срок (1/7/30 дней) и сколько человек может воспользоваться (1–20). Получаете ссылку вида `https://адрес/?invite=…`, отправляете в мессенджер. Родственник открывает, придумывает логин и пароль — и сразу попадает в ваше древо. Ссылка показывается один раз, на сервере хранится только её хеш; её можно отозвать в том же окне.
- Родственники **могут** добавлять и править людей, фото и связи. **Не могут**: приглашать других, удалять древо, управлять доступом. Всё, что они меняют, видно в «Истории» с их именем, любая правка откатывается.
- `ROD_REGISTRATION=open` — открыть регистрацию всем (не рекомендуется в интернете), `closed` — вообще закрыть новые аккаунты.

## Способ 1. Телефон + туннель Cloudflare (быстро, без денег и без своего адреса)

Подходит, чтобы **попробовать** или собирать данные «сессиями» («в воскресенье включаю телефон — заходите»).

```bash
pkg install cloudflared
cd ~/rod
TRUST_PROXY=1 npm start            # окно 1 (TRUST_PROXY нужен для HTTPS-cookie и защиты от перебора паролей)
cloudflared tunnel --url http://localhost:3000     # окно 2: напечатает https://что-то.trycloudflare.com
```

1. Откройте в приложении выданный адрес `https://….trycloudflare.com` (не `localhost`).
2. «Пригласить по ссылке…» — в поле «Адрес сервера» подставится он же. Отправьте ссылку.
3. Пока телефон включён, Termux не уснул (`termux-wake-lock`) и туннель запущен, родственники работают.

Минусы: **адрес меняется при каждом запуске туннеля** (старые ссылки перестают открываться — создавайте приглашения после запуска); если телефон выключен или без интернета, никто не зайдёт; гарантий доступности нет. Постоянный адрес даёт «именованный туннель» Cloudflare, но он требует своего домена (~1000 ₽/год) и аккаунта Cloudflare — см. документацию Cloudflare Tunnel.

## Способ 2. Постоянный сервер в интернете (рекомендуется, если древо ведёте долго)

Любой дешёвый VPS (от ~300–500 ₽/мес) с Docker. Тогда сервер работает всегда, телефон не нужен, адрес постоянный, а родственники могут установить «Род» как приложение (по HTTPS это разрешено).

`docker-compose.yml`:
```yaml
services:
  rod:
    build: .
    restart: unless-stopped
    environment:
      TRUST_PROXY: "1"
      PUBLIC_URL: "https://rod.example.com"
    volumes: ["./data:/data"]
  caddy:                         # сам получит и продлит HTTPS-сертификат
    image: caddy:2
    restart: unless-stopped
    ports: ["80:80", "443:443"]
    volumes: ["./Caddyfile:/etc/caddy/Caddyfile", "caddy:/data"]
volumes: { caddy: {} }
```
`Caddyfile`:
```
rod.example.com {
  reverse_proxy rod:3000
}
```
Нужен домен (или поддомен), направленный A‑записью на IP сервера. Данные лежат в `./data` — туда же пишутся файловые копии версий; ручную копию делайте кнопкой «Полная копия» или `docker compose exec rod node tools/backup.mjs --out /data/backups`. Перенести данные с телефона: сделайте полную копию, положите на сервер и выполните `node tools/restore.mjs full …` при остановленном контейнере.

## Способ 3. Tailscale (закрытая сеть семьи, без публичного адреса)

Каждый родственник ставит приложение Tailscale, вы приглашаете их в свою сеть, они открывают адрес вашего телефона внутри неё. Ничего не выставляется в интернет, но **каждому нужно установить и настроить приложение** — для не слишком технических родственников сложнее, чем ссылка.

## Безопасность — коротко

- Только **HTTPS** (оба первых способа его дают). По обычному `http://IP` пароли идут открытым текстом.
- Запускайте с `TRUST_PROXY=1` за туннелем/прокси — иначе все запросы выглядят как один IP и защита от подбора паролей работает хуже, а cookie не получает флаг Secure.
- Приглашения делайте на нужное число людей и с коротким сроком; ненужные отзывайте.
- Просите родственников использовать нормальные пароли (минимум 8 символов, сервер требует).
- Делайте копии (`npm run backup` или кнопка в меню): чужая ошибка тоже откатывается из «Истории», но копия защищает от потери всего.
- В «Полной копии» лежат аккаунты (хеши паролей) всех — храните файл как личные данные.

## Проверено / не проверено

Проверено автотестами: регистрация только по приглашению, одноразовые/многоразовые ссылки, срок, отзыв, права владельца, сгорание ссылки только при успешной регистрации, «вы уже в этом древе» при повторном открытии, полный сценарий в Chromium (владелец создаёт ссылку → родственник из чистого браузера регистрируется и видит древо). **Не проверено**: сами туннели и хостинг (в среде разработки нет интернета) — команды выше стандартные, но на вашем телефоне/сервере их надо прогнать и убедиться; адрес `trycloudflare.com` и формат вывода могут отличаться.
