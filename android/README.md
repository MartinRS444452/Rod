# «Род» для Android: что выбрать

**Рекомендуется — установка как приложения (PWA), без сборки.** См. `АНДРОИД.md` в корне проекта. Это настоящее приложение (значок, окно без адресной строки, офлайн-оболочка), а скачивание копий и архивов, выбор фото из «Google Фото» и обновления работают так же, как в Chrome.

Папка `android/` — запасной вариант: **оболочка Capacitor** (APK), которая при первом запуске спрашивает адрес вашего сервера, запоминает его и открывает «Род» внутри приложения.

## Ограничения оболочки (честно)
- **Не собиралась и не запускалась** (в среде разработки нет Android SDK и интернета). Файлы и сборочный сценарий написаны, но не проверены.
- WebView не умеет **скачивать файлы** (кнопки «Скачать архив», «Полная копия», SVG-плакат) — для этого в оболочку нужно добавлять отдельный код. В PWA/Chrome это работает.
- Нет автообновления интерфейса через Chrome и «установки из браузера» — только APK.

## Сборка (если всё же нужна)
GitHub Actions: загрузите проект в репозиторий → вкладка Actions → «android-apk» → Run workflow → скачайте `app-debug.apk`. Или локально (JDK 17+, Android SDK):
```bash
cd android && npm install && npx cap add android
sed -i 's#<application#<application android:usesCleartextTraffic="true"#' android/app/src/main/AndroidManifest.xml   # только если сервер по http://
npm run apk        # → android/app/build/outputs/apk/debug/app-debug.apk
```
Адрес сервера вводится при первом запуске. Debug-APK не подходит для Google Play (нужна подписанная release-сборка).
