# «Род» для Windows (Electron)

Не запускалось в среде разработки (там нет Windows и Electron) — проверена только логика запуска встроенного сервера (`node smoke.mjs`).

## Сборка установщика
Нужны Node.js 22+ и Windows (или GitHub Actions — см. `.github/workflows/desktop.yml`).

```bash
cd desktop
npm install
npm run dist        # → desktop/dist/Род Setup x.y.z.exe и портативная версия
npm start           # запуск без установки, для проверки
```

## Как работает
- По умолчанию внутри приложения запускается свой сервер на `127.0.0.1:38417`, данные лежат в профиле пользователя
  (`%APPDATA%\Род\data`). Это личное офлайн-приложение: аккаунты и древа — только на этом компьютере.
- Чтобы работать с вашим общим сервером (совместное редактирование между людьми и устройствами), создайте
  `%APPDATA%\Род\config.json`:  `{ "serverUrl": "https://ваш-сервер" }` — окно просто откроет его.
- Меню → «Открыть папку с данными и настройками» — быстрый доступ к данным и `config.json`.

## Требования Electron
`node:sqlite` нужен Node 22.13+, поэтому Electron ≥ 35 (в `package.json` указан ^37).
Подпись установщика (Authenticode) не настроена: Windows SmartScreen при первом запуске покажет предупреждение.
